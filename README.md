# 地獄蟻漫步 Hell Ant Walker

用方向鍵或螢幕上的十字鍵操控一隻 Kurzgesagt 平面風的地獄蟻（Haidomyrmecinae）。

**▶ https://van682112.github.io/hell-ant/**

| 操作 | |
|---|---|
| ↑ ↓ | 前進 / 後退（動畫自動倒放） |
| ← → | 轉向 |
| 左鍵拖曳 | 環繞 |
| 右鍵拖曳 | 平移 |
| 滾輪 | 縮放 |
| ☰ | 展開 / 收合控制面板 |

手機直接用右下角的十字鍵，面板預設收起。

## 這是什麼

模型在 Blender 建好、上好 Kurzgesagt 風格的平面著色，再把**每一個效果**重寫成
three.js 的 `ShaderMaterial`，參數同名同值：

| 效果 | 做法 |
|---|---|
| 兩色調 | `normalize(Incoming × 0.62 + L)` 與法線點積，硬邊切兩個平塗色 |
| 描邊 | 反向外殼（`BackSide` + 頂點沿法線外推），**線寬鎖定 3 像素**，不隨鏡頭距離改變 |
| 腹部條紋 | 讀 `COLOR_0.r`（腹部沿長軸的正規化座標），乘法壓暗而非換色 |
| 眼睛高光 | **解析反射點** —— 把眼睛當拋物面圓頂，用半向量解出反射點座標，不是 Blinn-Phong |
| 眼圈 | 讀 `COLOR_0.g`（到眼睛島嶼邊界的距離），線跨過材質交界畫在兩側 |
| 地板陰影 | `step(0.5, getShadowMask())` 切成硬邊平塗兩色 |

模型 46,666 三角面 + 同樣面數的描邊外殼，53 根骨頭，16 格走路循環。
渲染 60 fps / 15 draw calls。
